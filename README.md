## 正在做 · Stardust Agent

一个面向大学生的开源申报材料工作台。学生可以上传学校通知和项目资料，检索申报要求，起草大创项目、挑战杯和奖学金申请等材料，再逐章编辑并导出 Word。

*An open-source workspace for student proposals and scholarship applications, with document search, section-by-section editing, and Word export.*

[打开在线工作台](https://agent.stardust.website) · [查看源代码](https://github.com/cuic19053-hue/stardust-agent) · [大创 Word 样例](https://github.com/cuic19053-hue/stardust-agent/blob/main/examples/demos/demo_innovation_research.docx)
